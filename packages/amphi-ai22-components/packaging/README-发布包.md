# AI22 零代码图表组件发布包

该包包含 50 个零代码图表组件，统一显示在“图表组件”侧栏类别中。
功能覆盖常用 20、高级 20、时序 7、实时 3 种图表。

扩展标识：

```text
@local-ai/amphi-ai22-components
```

安装：

```bash
tar -xzf amphi-ai22-components-1.0.1.tar.gz
cd amphi-ai22-components-1.0.1
./install.sh /absolute/path/to/python-venv
```

无虚拟环境时：

```bash
./install.sh --user --python /absolute/path/to/python3
```

成功标志：

```text
@local-ai/amphi-ai22-components v1.0.1 enabled OK
```

图表文件为自包含 HTML/SVG，不需要浏览器访问外部 CDN。
