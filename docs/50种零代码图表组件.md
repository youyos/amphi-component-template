# 50 种零代码图表组件

需求 22 作为独立扩展交付：

```text
@local-ai/amphi-ai22-components
```

扩展提供共 50 个组件，全部统一显示在“图表组件”侧栏类别中。
功能上覆盖常用、高级、时序和实时图表；下列小节仅用于说明功能范围，
不会在 Amphi 侧栏中拆分为多个类别。输入均为 pandas DataFrame，输出保留原始数据并自动
增加 `ai22_chart_path`、`ai22_chart_type` 和 `ai22_chart_rows`。图表保存为自包含
HTML/SVG 文件，不依赖 ECharts CDN、在线地图或其他浏览器网络资源。

## 组件目录

### 常用图表组件（20）

柱线组合图、纵向组合图、玫瑰图、仪表盘、文字 KPI、水球图（KPI）、行政地图、
标记地图、迁徙地图、列表、交叉表、自由式报表、柱状图、折线图、饼图、散点图、
面积图、气泡图、雷达图、环形图。

### 高级图表组件（20）

旭日图、玉玦图、矩形树图、漏斗图、关系图、词云图、瀑布图、箱线图、桑基图、
力向导图、热力图、甘特图、平行坐标图、小提琴图、密度图、日历热力图、弦图、
极坐标图、层级边捆绑图、地理热力图。

### 时序图表组件（7）

时序线图、时序柱图、时序面积图、时序仪表盘、时序水球图、时序散点图、
时序热力图。

### 实时图表组件（3）

实时线图、实时标签图、实时仪表盘。

## 使用约定

- 分类图：选择分类字段和数值字段，可配置求和、平均、计数、最大或最小聚合。
- 地图：标记地图和地理热力图使用经纬度字段；行政地图使用行政区域名称和值；
  迁徙地图使用来源、目标和值。
- 关系图：关系图、桑基图、力向导图、弦图和边捆绑图使用来源、目标和权重。
- 时序图：选择可解析的时间字段，运行时会按时间排序。
- 实时图：配置刷新间隔和数据窗口，生成的 SVG 使用内置动画轮播最新窗口快照。
- 表格报表：列表与自由式报表可选择展示字段，留空时使用全部字段。

地图组件采用无需外部底图的离线坐标或区域块渲染。经纬度图按输入坐标进行
等距投影，适合教学、内网和离线环境。
