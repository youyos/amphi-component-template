# 75 种零代码算法组件

本扩展将 75 个 `pandas_df_processor` 节点注册到 Amphi。所有节点均复制输入
DataFrame，不原地修改源数据，并生成三个变量：

```python
输出名, 输出名_model, 输出名_metrics = run_amphi_zero_code_algorithm(...)
```

每个节点使用独立 SVG 图标：图形轮廓表达算法类别，C4.5、XGB、KNN、ARIMA、
AHP、UCF 等名称缩写用于区分具体算法，不再复用同一个通用图标。

## 组件目录

| 分组 | 数量 | 组件 |
|---|---:|---|
| 机器学习组件 | 51 | 分类 10、聚类 8、回归 10、关联 5、时间序列 8、综合评价 5、推荐 5 |
| 集成学习组件 | 4 | Bagging 分类、Bagging 回归、Voting 分类、Voting 回归 |
| 深度学习组件 | 5 | DNN 分类、DNN 回归、RNN 分类、RNN 回归、LSTM 预测 |
| 文本分析组件 | 10 | 分词、信息抽取、文本过滤、向量空间、关键词提取、命名实体识别、文本相似度、观点情感分析、文本分类、主题建模 |
| 自动学习组件 | 5 | 自动择参、自动分类、自动回归、自动聚类、一键建模 |
| 合计 | 75 | 5 个侧边栏分组 |

“机器学习组件”仅合并 Amphi 侧边栏分组；51 个组件仍保留各自的算法类型、
专用参数表单、运行逻辑、结果字段和唯一图标。

## Java 编程执行组件

扩展另外注册一个非算法类 `pandas_df_processor` 节点：

| 分组 | 组件 | 功能 |
|---|---|---|
| 编程语言组件 | Java 编程执行 | 编译并执行 `.java` 源文件或内联 Java 代码 |

该组件不会把 Java 源码直接插入 Python 单元格。生成的 Python 包装代码通过
`subprocess` 以参数数组依次调用 `javac` 和 `java`，不使用 shell。输入 DataFrame
会写入临时 `input.csv`，Java `main` 方法会收到：

```text
args[0] = 输入 CSV 绝对路径
args[1] = 输出 CSV 绝对路径
args[2...] = 表单中填写的附加参数
```

Java 写入 `args[1]` 后，组件自动将结果 CSV 读回 DataFrame；未写入时可保留输入
数据，或选择输出标准输出/错误输出日志表。组件还支持主类自动识别、外部
Classpath、编译/运行超时和执行产物持久化。

Java 程序与 JupyterLab 服务器进程拥有相同权限，只应运行可信代码。使用该组件
需要 JDK（同时提供 `javac` 和 `java`）；算法组件本身不依赖 JDK。

## 专用组件设计

75 个节点各自显示本算法有意义的配置项，不再要求用户填写技术性的输出字段。例如：

- C4.5+：测试集比例、剪枝开关、叶节点最少样本数。
- KNN：邻居数量 K、距离加权。
- 随机森林：决策树数量、最大深度、叶节点最少样本数。
- DBSCAN：邻域半径 Eps、核心点最少样本数。
- ARIMA：p、d 和预测步数。
- Apriori：最小支持度、最小置信度。
- 矩阵分解推荐：潜在因子数量、正则化强度。
- Bagging：基学习器数量、样本比例和特征比例。
- DNN/RNN/LSTM：隐藏单元、学习率、递归谱半径或门控参数。
- 文本分析：词汇规模、N-Gram、关键词数、主题数或抽取类型。
- 自动学习：候选方案数量、交叉验证折数和自动目标选择。

结果字段由组件自动使用算法唯一名称生成，例如
`c45_plus_classifier_prediction`，避免把输出列名误解为算法参数。

## 输入配置

- 分类和回归：选择目标列与特征列。目标缺失行不会参与训练，但会保留并产生预测。
- 聚类：选择特征列；留空时使用全部数值列。
- 关联：事务项目列支持逗号分隔字符串或 Python 列表。
- 时间序列：选择数值列；高级参数为窗口或向前预测步数。
- 综合评价：选择多个数值指标；结果字段为综合得分。
- 推荐：用户列放在“目标列”，特征依次选择物品列和可选评分列。
- 分类与回归组件使用测试集计算独立评估指标，并使用全部已标注数据生成最终模型。
- 高级参数“随机种子”固定为同一值时，含随机过程的算法可复现。
- 输出字段若已存在会明确报错，避免静默覆盖源字段。

## 运行依赖

```text
Python >= 3.11
JupyterLab >= 4.3.4, < 5
jupyterlab-amphi >= 0.9.0, < 1
pandas >= 2.0, < 3
numpy >= 1.26, < 3
scikit-learn >= 1.5, < 2
```

为了适应本机 macOS 环境，XGBoost 节点在系统缺少 `libomp` 时使用
scikit-learn 的直方图梯度提升实现同类提升树工作流；ARIMA 等时间序列节点使用
扩展内的可移植实现，不强制安装 `statsmodels`。
