# 模型评估与管理组件

需求 14 作为独立 JupyterLab 扩展交付：

```text
@local-ai/amphi-ai14-components
```

9 个组件统一显示在“模型评估与管理组件”类别中。

## 组件清单

| 功能 | 组件 | 主要输出 |
|---|---|---|
| 二分类评估 | K-S 模型评估 | K-S 统计量、最优阈值、累计分布曲线 |
| 二分类评估 | PR 模型评估 | Precision-Recall 曲线、Average Precision |
| 二分类评估 | ROC 模型评估 | ROC 曲线、AUC |
| 分类评估 | 分类模型综合评估 | Accuracy、Balanced Accuracy、Precision、Recall、F1 |
| 回归评估 | 回归模型综合评估 | MAE、MSE、RMSE、R²、MAPE |
| 模型比较 | 最优模型选择 | 模型排名、最优模型标记、最优指标 |
| 模型管理 | 模型输出 | Joblib/Pickle 文件及 SHA-256 描述 |
| 模型管理 | 模型读取 | 模型描述 DataFrame 和运行期模型注册 |
| 模型应用 | 模型利用 | 新数据预测结果和可选分类概率 |

## 推荐流程

评估和选择：

```text
建模组件 → 评估组件 → 合并多个评估结果 → 最优模型选择
```

模型保存和再次利用：

```text
建模组件 → 模型输出
模型读取 + 待预测数据 → 模型利用
```

“模型输出”直接连接现有建模组件时，会自动使用上游 DataFrame 对应的
`<输出变量>_model`，一般不需要填写模型变量名。模型输出字段名自动生成，
不会要求用户手工填写预测类别字段。

K-S、PR 和 ROC 需要二分类真实值字段和连续概率/评分字段。分类综合评估需要
真实值与预测类别字段；回归综合评估需要真实值与预测数值字段。

## 模型文件安全

Joblib 和 Pickle 使用 Python 反序列化机制，可能执行文件中包含的代码。只能读取
可信来源的模型文件。模型描述 DataFrame 包含路径、格式、SHA-256、模型类型、
训练行数和特征名，便于审计和迁移。
