# 分析计算组件

需求 24 作为独立扩展交付：

```text
@local-ai/amphi-ai24-components
```

19 个组件全部统一显示在“分析计算组件”侧栏类别。每个组件都接收
pandas DataFrame，自动命名输出列，并输出 `<output>_model` 和
`<output>_metrics`。

## 组件清单

| 功能范围 | 组件 |
|---|---|
| 聚合计算 | 合计计算、计数计算、总体标准差、总体方差、平均值计算 |
| 计算函数 | 数值函数计算、文本函数计算、日期函数计算、条件函数计算、窗口函数计算 |
| 复杂指标 | 同比分析、环比分析、累计占比分析 |
| 预警与格式 | 数据预警分析、多样条件格式 |
| 高级分析 | 趋势线拟合、参考线分析、时序预测分析、聚类分析 |

## 关键行为

- 聚合计算支持多字段分组和忽略、补 0、严格报错三种缺失值策略。
- 总体标准差和总体方差使用 `ddof=0`。
- 同比按月、季、年对比上年同期；环比对比上一日、月、季或年。
- 预警支持大于、小于、等于、区间、区间外、空值等规则。
- 条件格式支持阈值高亮、连续色阶、数据条、图标集，同时生成自包含 HTML 报表。
- 趋势线输出拟合值、残差、R² 和 RMSE；时序预测会追加未来时间点。
- 聚类分析支持特征标准化、确定性随机种子、簇中心距离、惯性和轮廓系数。
