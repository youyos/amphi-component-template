# 多语言、图形与文档报告组件

这 7 个零代码组件和一个 JupyterLab“文档报告”设计面板已经拆分为独立扩展，
不再由 75 个算法组件所在的主扩展注册。

扩展标识和安装目录为：

```text
@local-ai/amphi-ai27-components
```

## 组件清单

| 分组 | 组件 | 输入/输出 |
|---|---|---|
| 平台扩展组件 | R 语言执行 | DataFrame → DataFrame |
| 平台扩展组件 | Python 语言执行 | DataFrame → DataFrame |
| 平台扩展组件 | JavaScript 脚本执行 | DataFrame → DataFrame |
| 平台扩展组件 | 图形报表生成 | DataFrame → DataFrame + SVG |
| 平台扩展组件 | 文档模板输入 | 模板文件 → 模板 DataFrame |
| 平台扩展组件 | 文档报告生成 | 数据 + 模板 → 报告 DataFrame |
| 平台扩展组件 | 文档报告导出 | 报告 DataFrame → 文件 |

## 独立构建与安装

```bash
./packages/amphi-ai27-components/scripts/build-and-install.sh \
  /absolute/path/to/python-venv
```

安装目录：

```text
<python-data-dir>/share/jupyter/labextensions/@local-ai/amphi-ai27-components/
```

生成独立发布包：

```bash
./packages/amphi-ai27-components/scripts/package-release.sh
```

三种脚本组件均支持源文件和内联代码、附加参数、运行超时、控制台日志及可选的
执行产物保存目录。程序在独立子进程中运行，不会把 R 或 JavaScript 源码直接当成
Python 执行。

## 脚本数据约定

Python 代码读取 `input` DataFrame，并将结果赋给 `output`：

```python
output = input.copy()
output["passed"] = output["score"] >= 60
```

R 代码读取 `input` data.frame，并将结果赋给 `output`：

```r
output <- input
output$passed <- output$score >= 60
```

JavaScript 代码读取 `input` 对象数组，并将结果赋给 `output`：

```javascript
output = input.map(row => ({
  ...row,
  passed: Number(row.score) >= 60
}));
```

运行依赖：

- Python 组件使用启动 JupyterLab 的同一个 Python 环境。
- R 组件需要服务器提供 `Rscript`。
- JavaScript 组件需要服务器提供 `node`。
- 所有脚本拥有与 JupyterLab 服务器相同的权限，只应运行可信代码。

## 图形报表

“图形报表生成”支持柱状图、折线图、散点图和饼图，生成不依赖 Matplotlib 的独立
SVG 文件。输出 DataFrame 自动增加 `amphi_chart_path`，供后续文档报告组件使用。

## 文档模板

支持 Markdown、HTML 和 DOCX 模板。推荐在模板中使用以下占位符：

```text
记录数：{{ metric:rows }}
平均成绩：{{ metric:平均分 }}
最高成绩：{{ calc:max:score }}
{{ table:成绩表 }}
{{ chart:default }}
```

“文档报告生成”的绑定 JSON 示例：

```json
{
  "metrics": {
    "平均分": "mean:score",
    "及格人数": "sum:passed"
  },
  "tables": {
    "成绩表": {
      "columns": ["name", "score", "passed"],
      "limit": 50
    }
  },
  "charts": {
    "default": "auto"
  }
}
```

支持的计算规则为 `count`、`mean`、`sum`、`min`、`max`、`median` 和
`nunique`。例如 `mean:score`、`count:*`。

Markdown 和 HTML 报告只使用 Python 标准库与 pandas。DOCX 报告需要额外安装：

```bash
pip install "python-docx>=1.1,<2"
```

## 文档报告设计面板

安装后，JupyterLab 右侧出现“文档报告”面板，可以：

1. 上传 Markdown、HTML 或 DOCX 模板到 Jupyter 文件目录。
2. 编辑并保存 Markdown/HTML 模板。
3. 选择指标、函数、表格或图形类型并插入占位符。
4. 下载“文档报告导出”组件生成的报告文件。

推荐流程：

```text
业务数据 ─→ 图形报表生成 ───────────┐
                                    ├→ 文档报告生成 → 文档报告导出
文档模板输入 ───────────────────────┘
```
